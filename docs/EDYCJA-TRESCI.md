# Як редагувати SUSHI & CHILL QR-menu

Усі зміни робіть у вихідних файлах, а не безпосередньо в `public/menu/**/index.html`: ці HTML-файли створюються автоматично командою `npm run build`.

## Як змінити назву категорії

1. Відкрийте `public/data/menu.json`.
2. Знайдіть позиції потрібної групи за `ID` або `NAZWA`.
3. Змініть значення `KATEGORIJA` у всіх позиціях цієї групи однаково.
4. Якщо для категорії є пояснення, змініть ключ у `public/data/category-notes.json` на нову назву.
5. Запустіть `npm run audit`, потім `npm run build`.

Зараз назва категорії береться безпосередньо з `KATEGORIJA`, тому на сторінках PL/UK/EN вона однакова. Для окремих перекладів назв категорій потрібне додаткове поле/словник локалізації.

## Як змінити попередження над меню

Відкрийте `public/assets/js/i18n.js` і відредагуйте потрібні поля окремо в `pl`, `uk`, `en`:

- `spicyNote` — доплата за гостру версію;
- `friedNote` — доплата за смажені футомакі;
- `ingredientNotice` — пояснення про скорочений перелік складників;
- `allergenSummary`, `allergenNote`, `allergenListTitle`, `allergenList` — блок інформації про алергени;
- `infoLine` — примітка про ціни та фотографії.

Не прибирайте застереження про скорочений перелік складників, доки на сайті не буде опубліковано повні перевірені рецептури для кожної страви.

## Після редагування

У корені проєкту:

```bash
npm ci
npm run audit
npm run build
npm run serve
```

Відкрийте `http://localhost:8000/menu/`, перевірте PL/UK/EN на телефоні й комп'ютері, пошук, переходи між категоріями, ціни, зображення та всі попередження. Для публікації завантажуйте саме каталог `public/` на Cloudflare Pages.

**Не редагуйте вручну** `public/menu/index.html`, `public/menu/ua/index.html`, `public/menu/en/index.html`, `public/sitemap.xml` і версії `?v=` у підключеннях CSS/JS: вони генеруються під час збірки.
