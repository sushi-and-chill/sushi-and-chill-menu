## Обмеження перевірки

Повну команду `npm run build` у середовищі аудиту не вдалося виконати: встановлення залежностей `npm ci` завершувалося тайм-аутом, тому відсутні/неповні `jsdom` і `sharp`. Статичні HTML-файли PL/UK/EN, sitemap, robots і версії кешу синхронізовано з внесеними змінами; після розпакування проєкту слід виконати `npm ci`, `npm run audit`, `npm run build` і перевірити результат локально перед деплоєм.

## Висновок

Архів придатний як оновлена технічна база QR-menu. Він **не підтверджує повної юридичної відповідності харчової інформації**, оскільки повні рецептури та специфікації постачальників не були надані. Перед тим як представляти сайт як повний перелік складу й алергенів, потрібно завершити пункти P0 у `PLAN-POPRAWY-I-CHECKLISTA-PL.md`.

## Обмеження збірки

Повторний `npm ci` у середовищі підготовки архіву завершився тайм-аутом, через що локально відсутній повний комплект залежностей `sharp`/`jsdom`. Тому повний `npm run build` після змін **не був підтверджений**. Готові статичні HTML-файли синхронізовано вручну з відповідними змінами шаблону та рендерера. Перед наступним деплоєм потрібно виконати `npm ci`, `npm run audit`, `npm run build` у звичайному середовищі розробки та перевірити локальний результат.
